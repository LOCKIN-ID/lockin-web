## Numbered Findings List

### 1. Em dash character (`—`) used across UI text, headings, and metadata
- **Rule:** R-02 (Hard Gate / antislop-copywriting)
- **Priority:** HIGH
- **Reason:** R-02 strictly forbids the em dash character (`—`) in UI text and metadata; replace with colon (`:`), pipe (`|`), comma (`,`), or parentheses `()`.
- **Files Affected:**
  - `src/app/layout.tsx` (site title and description)
  - `src/app/(admin)/admin/**/page.tsx` (all admin metadata titles)
  - `src/app/(app)/app/**/page.tsx` (dashboard and user section metadata titles)
  - `src/app/(marketing)/books/[slug]/page.tsx`
  - `src/app/(marketing)/page.tsx`

### 2. Color contrast below 4.5:1 on small text using `--color-muted`
- **Rule:** R-25 (Hard Gate / antislop-human)
- **Priority:** HIGH
- **Reason:** `--color-muted` (`oklch(48% 0.025 154)` ≈ `#607567`) against `--color-paper` (`#F1F1EB`) yields a 4.37:1 ratio, failing WCAG AA 4.5:1 threshold for normal/small text (`--text-xs`, `--text-sm`).
- **Files Affected:**
  - `src/app/tokens.css` (line 14)
  - `src/app/(app)/app/page.tsx` (small captions and timestamp labels)
  - `src/app/(admin)/admin/page.tsx` (metric card labels)

### 3. Touch target height below 44px on mobile devices (`.btn--sm`)
- **Rule:** R-03 (Hard Gate / antislop-layoutmobile / antislop-human)
- **Priority:** HIGH
- **Reason:** `.btn--sm` specifies `min-height: 36px` without minimum 44px tap target area or mobile touch compensation.
- **Files Affected:**
  - `src/app/base.css` (line 107)

### 4. Trailing arrows glued to button and link text (`&rarr;` / `→`)
- **Rule:** R-08 (Purpose-Gate / antislop-ui)
- **Priority:** MEDIUM
- **Reason:** Inline arrow characters (`&rarr;`) appended directly to CTA labels without dedicated icon container or articulated hierarchy purpose.
- **Files Affected:**
  - `src/app/(app)/app/quests/page.tsx`
  - `src/components/reader/block-renderer.tsx`
  - `src/components/reader/checkpoint.tsx`
  - `src/components/reader/section-body.tsx`

### 5. Uppercase text transform applied to descriptive metric labels
- **Rule:** R-06 (Purpose-Gate / antislop-ui)
- **Priority:** MEDIUM
- **Reason:** `textTransform: "uppercase"` used on metric labels contrary to `design.md` and R-06 untracked sentence-case standard.
- **Files Affected:**
  - `src/app/(admin)/admin/page.tsx`
  - `src/app/(app)/app/page.tsx`

### 6. Generic CTA wording "Explore Help Centre"
- **Rule:** R-15 (Quality Locks / antislop-copywriting)
- **Priority:** LOW
- **Reason:** "Explore" is a generic template verb banned in CTAs; replace with specific action such as "Visit Help Centre" or "Browse Help Topics".
- **Files Affected:**
  - `src/app/(marketing)/contact/page.tsx` (line 55)

### 7. Decorative banner comment separators in CSS files
- **Rule:** R-31 (Quality Locks / antislop-code)
- **Priority:** LOW
- **Reason:** ASCII banner comments (`/* ---- controls: ... ---- */`, `/* ---------------- */`) add visual noise without code information.
- **Files Affected:**
  - `src/app/base.css`
  - `src/app/globals.css`
